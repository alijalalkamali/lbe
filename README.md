# LLM Behavioral Eval

A rigorous behavioral evaluation framework for small open-weights LLMs (Llama 3.2 0.5B–3B, Qwen 2.5 0.5B–1.5B). Measures steerability, consistency, and faithfulness with proper statistical rigor — bootstrap confidence intervals, multiple seeds, paired comparisons. Triangulates behavioral findings with interpretability-light analysis (linear probes, activation patching) to distinguish what information is *available* in model representations from what is *causally used*.

Portfolio project targeting Anthropic Alignment Science research roles.
