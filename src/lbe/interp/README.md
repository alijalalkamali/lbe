# lbe.interp — probing pipeline (status)

Drop `src/lbe/interp/` into your repo's `src/lbe/interp/` (replacing the
empty package), and the two test files into `tests/`.

## Built & tested (20/20 passing)
- `hooks.py`   — ActivationCache (forward-hook capture, context-managed cleanup)
- `config.py`  — hardware profiles: local_dev = fp16/eager (Pascal-safe), rental_gpu = bf16/flash_attn2
- `data.py`    — three-way join (items_v3 × steerability_v2 results × aggregated_judgments.csv),
                 verified against the real CSV: 100 items, derail=42 / full-compliance=57 / disavowal=1.
                 Prompt reconstruction matches steerability_v2.py exactly (base_prompt alone;
                 steering_instruction alone). Boundary = last prompt token, prefix-verified.
- `probe.py`   — nested CV (outer 5 / inner 3), L2 grid over C∈{1e-4..1}, balanced accuracy,
                 200-permutation null with Phipson-Smyth p-values, per-layer sweep, JSON output.
                 Statistical behavior tested against synthetic known-truth data, including the
                 critical case: pure noise at n≪d is NOT reported as signal.
- Deps to add to pyproject: torch, transformers, accelerate, scikit-learn, numpy.

## Not built yet
